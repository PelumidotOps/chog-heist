# Game concept

## Player promise

Chog Heist is a readable, replayable stealth-extraction game that runs in the browser. A player has three minutes to enter a high-security futuristic vault, choose a route, collect crystals, and reach extraction. Detection increases pressure; greed increases risk.

## Core loop

1. Review the vault and prepare a loadout.
2. Infiltrate while observing guard patrols and laser timing.
3. Collect crystals and optional high-risk objectives.
4. Decide whether to push deeper or extract safely.
5. Receive a score based on loot, time, alerts, and optional objectives.

## Design pillars

- **Readable stealth:** danger, line of sight, noise, and interactable objects should be visually clear.
- **Short consequential runs:** a three-minute ceiling supports replay and meaningful risk decisions.
- **Free access:** owning an NFT is never required to play the core game.
- **Useful ownership:** the planned NFT feature authorizes gameplay traits, not access to the game.
- **Respectful scope:** the initial product is single-player and deliberately avoids premature multiplayer complexity.

## Planned trait lending

A Chog Genesis NFT owner may eventually grant a borrower permission to use one NFT-derived gameplay trait until a defined expiry. The NFT remains in the owner’s wallet. The game should validate an authorization and translate a known, verified trait identifier into a bounded gameplay modifier.

No real collection traits are represented in the current build. Gameplay balance, source metadata, contract behavior, revocation, expiry, indexing, and security must be specified and verified before integration.
